## 🧠 JavaScript Functionality

The calculator uses JavaScript functions for different operations:

### `appendValue()`

Adds numbers and operators to the display.

### `clearDisplay()`

Clears the calculator display.

### `deleteLast()`

Removes the last entered character.

### `calculate()`

Evaluates the entered mathematical expression and displays the result.

### Keyboard Support

A `keydown` event listener allows users to operate the calculator using their keyboard.
